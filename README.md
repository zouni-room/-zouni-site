# 雑煮｜GitHub Pages site

スマートフォン向けの個人サイトです。GitHub Pagesで公開できます。

## ファイル
- `index.html` — ページ本文
- `style.css` — デザイン、アニメーション、ライト／ダークテーマ
- `script.js` — メニュー、検索、テーマ切替、上部へ戻るボタン

## 更新方法
GitHubリポジトリの各ファイルを編集するか、ファイルをアップロードして置き換えてください。公開反映には数分かかることがあります。

## 機能
- 作品一覧の開閉と控えめな表示アニメーション
- スクロール時のフェードイン
- 画面右下のページ上部へ戻るボタン
- 作品名・キャラクター名・一部略称で検索
- ライト／ダークテーマ切替（対応ブラウザでは端末ごとに選択を保存）
- 動きを減らすOS設定への配慮
